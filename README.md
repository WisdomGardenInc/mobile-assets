# mobile-assets

English · [简体中文](README.zh-CN.md)

This repository hosts static resources used by TronClass and mhesi apps, along
with browser tools for development and release maintenance.

[Browser tools](https://wisdomgardeninc.github.io/mobile-assets/pages/tools/) · [Release guide](https://github.com/WisdomGardenInc/mobile-assets/blob/master/RELEASING.md) · [Asset list](https://github.com/WisdomGardenInc/mobile-assets/blob/master/assets-list.md)

## Main files and directories

| Resource | Purpose |
| --- | --- |
| `version_update*.json`, `version_aligner.json` | App update notices and LMS compatibility. |
| [`app-legal/`](https://github.com/WisdomGardenInc/mobile-assets/tree/master/app-legal) and root legal files | Privacy policies, user agreements, and app market review snapshots. |
| [`callback.html`](callback.html), [`identity-web-login-proxy/`](identity-web-login-proxy/) | Native App identity login resources. |
| [`youtube-video-analysis.html`](youtube-video-analysis.html) | In-app YouTube playback and viewing statistics. |
| [`mhesi/`](mhesi/) | mhesi version, login, and app association resources. |
| [`pages/`](pages/) | Internal browser tools and release verification pages. |
| [`scripts/`](scripts/) | Version configuration sync, npm releases, and CDN refreshes. |
